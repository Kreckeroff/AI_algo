# Experiments

Скрипты и ноутбуки обучения (контур **A** и позже ранжировщик графов).

## Правила

- Сырые датасеты — в `data/raw/` (в `.gitignore`) или внешний путь; в git только маленькие сэмплы / схемы.
- Артефакты моделей (`*.joblib`, `*.onnx`) — не коммитить по умолчанию; описание эксперимента — да.
- Каждый эксперимент: папка `YYYY-MM-DD-short-name/` + `README.md` (гипотеза, фичи, метка, метрики OOS).
- Воспроизводимость: зафиксировать версии пакетов (`requirements.txt` или `pyproject.toml` в корне experiments позже).
