## Модель

**AI_algo** — самостоятельный продукт (сервис + модели + спеки + **UX-клиенты**).  
Клиенты:

1. **Standalone** — отдельный релиз: чат, сборщик стратегий, CSV/брокер.
2. **IT Algo Desktop** — тот же AI **из коробки** (чат, сборка, compare) поверх native graph/бэктеста.

```text
┌─────────────────────┐         контракты API / события          ┌─────────────────────┐
│  Desktop /          │  ────── данные (ноды, бары, CSV, …) ──► │      AI_algo         │
│  Standalone clients │  ◄──── ответы (граф, вердикт, чат) ──── │  (inference + train) │
└─────────────────────┘                                          └─────────────────────┘
         │  strategy file (.italgo / GraphDTO)  │
         └──────────────────────────────────────┘
```

Обучение и веса остаются в AI_algo; UI-оболочки — тонкие клиенты. Прод Desktop **не** вшивает train в релизное ядро.

## Что принадлежит кому

| Зона | AI_algo | IT Algo Desktop | Standalone client |
|------|---------|-----------------|-------------------|
| Модели, веса, пайплайн обучения | ✅ | ❌ | ❌ |
| DSL/схема графа (канон) | ✅ контракт + валидатор | ✅ runtime | ✅ UI сборщика по контракту |
| UI чата / AI-панели | спека + API | ✅ из коробки | ✅ главный UX |
| UI конструктора блоков | контракт GraphDTO | ✅ native | ✅ свой сборщик «как IT Algo» |
| Бэктест-движок | оркестрация / vectorized lab | ✅ prod engine | лёгкий / через API |
| CSV upload | ingest схема | опц. | ✅ P0 |
| Брокерские коннекторы | — | ✅ есть | ✅ нужны для отдельного релиза |
| Экспорт/импорт стратегии | формат файла | ✅ | ✅ |
| Квоты / биллинг AI | gateway / site | показывает лимиты | показывает лимиты |

## Два режима данных для обучения

| Режим | Когда | Как |
|-------|-------|-----|
| **Export** | prod / любой стенд | Desktop (или CI) выгружает ноды, OHLCV, фичи, бэктесты → AI_algo ingest / файлы |
| **Dev-integrated** | ветка `dev` / `ai-train` | Desktop стримит или пушит батчи в AI_algo Train API |

## Данные для пользователя (runtime)

| Источник | Standalone | Desktop |
|----------|------------|---------|
| CSV / файл OHLCV | ✅ | опц. |
| Брокер напрямую | ✅ (цель) | ✅ уже |
| Ingest после бэктеста | через API | ✅ `ai-train` |

Прод-релиз Desktop **не** обязан уметь учить модель — только inference, чат/compare и (по политике) телеметрию/экспорт.
