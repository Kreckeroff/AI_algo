## Одна фраза

**AI_algo** — отдельный продукт с полным UX (чат, сборщик стратегий, данные).  
Тот же функционал **из коробки** встраивается в **IT Algo Desktop**.  
Стратегии можно **выгрузить файлом** и открыть в Desktop / нашем решении.

## Два канала поставки (один продукт)

```text
                    ┌─────────────────────────────┐
                    │         AI_algo             │
                    │  Chat · Builder · Data ·    │
                    │  Compare · Signal · Export  │
                    └─────────────┬───────────────┘
                                  │
              ┌───────────────────┼───────────────────┐
              ▼                                       ▼
┌─────────────────────────┐           ┌─────────────────────────────┐
│  Standalone app / web   │           │  IT Algo Desktop (из коробки)│
│  отдельный релиз        │           │  тот же AI UX + native graph │
│  свой сборщик + чат     │           │  + бэктест / брокер Desktop  │
└─────────────────────────┘           └─────────────────────────────┘
              │                                       │
              └──────── strategy file (.italgo / DSL) ┘
```

| Канал | Что получает пользователь |
|-------|---------------------------|
| **Standalone** | Независимый продукт: чат + сборщик стратегий + загрузка данных / брокер → работа без Desktop |
| **IT Algo Desktop** | Тот же AI-функционал **с коробки** (чат, сборка, советы, compare), поверх native конструктора и бэктеста |
| **Обмен** | Экспорт стратегии в файл → импорт в Desktop / standalone / другое наше решение |

Обучение моделей и inference остаются в AI_algo; UI-оболочки — клиенты одного API.

## UX-поверхности (обязательные)

### 1. Полноценный чат

- Диалог с ИИ: комментарии по стратегиям, разбор сделок/метрик, советы по доработке.
- ИИ **создаёт и правит** стратегии из чата (вызов Builder / apply graph).
- Контекст: текущий граф, последний бэктест, загруженные данные, история правок.
- Не «один shot промпт», а сессия с памятью артефактов (версии скрипта, вердикты compare).

### 2. Сборщик стратегий (как в IT Algo)

- Low-code / block graph: индикаторы, входы/выходы, риск, TF — **паритет идей** с Desktop.
- Синхронизация с чатом: ИИ собрала → граф появился в сборщике; пользователь подвигал блоки → чат видит diff.
- Валидатор DSL + понятные ошибки.
- В Desktop — либо встроенная панель AI рядом с native конструктором, либо общий GraphDTO.

### 3. Данные: ручная загрузка + брокер

| Способ | MVP-идея | Зачем |
|--------|----------|-------|
| **CSV / файл** | OHLCV (и опц. trades) по схеме export | offline / кастомные ряды без брокера |
| **Прямое подключение брокера** | Finam / Tinkoff / др. (как в Desktop) | live и история «из коробки» в standalone |
| **Ingest из Desktop** | уже есть auto-ingest / export | обучение и compare в лаборатории |

Standalone без данных бесполезен: загрузка CSV и/или брокер — **P0 для отдельного релиза**.

### 4. Экспорт / импорт стратегии

- Выгрузка: `.italgo` / canonical GraphDTO / JSON по контракту.
- Вставка в IT Algo Desktop и обратно.
- Цель: пользователь может жить в standalone-AI, а исполнение/прод-алго — в Desktop (или наоборот).

## Что «с коробки» в Desktop

Не «урезанный виджет», а **тот же AI-слой**:

- [ ] Чат (комментарии + создание/правка стратегий)
- [ ] Compare + trade analysis
- [ ] Builder из промпта / чата в native graph
- [ ] (по политике) Signal / Advisor
- [ ] Импорт файла стратегии из standalone

Отличие Desktop: свой движок бэктеста, брокерские коннекторы, прод-скрипты.  
Standalone: свой UI сборщика + свои коннекторы данных, тот же backend AI_algo.

## Приоритет относительно обучения

| Сейчас (train-first) | Потом (UX продукт) |
|----------------------|--------------------|
| Сигнал-модель, семейства скриптов, ingest | Чат UX, standalone shell, CSV/broker UI |
| Desktop `ai-train` лаборатория | Паритет UX в prod Desktop + отдельный релиз |

Полированный prod UI — **после** того, как модели и compare дают пользу; этот документ фиксирует **целевой UX**, чтобы не потерять scope.
